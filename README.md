# SmartTravelPlanner ✈️

A modern desktop route planning application built with **C# (.NET 10)**, **Avalonia UI**, and the **MVVM architecture pattern**.

## 🌟 Key Features
- **Traveler Management:** Create and customize traveler profiles.
- **Route Computation:** Find the shortest path and distance between cities using **Dijkstra's Algorithm**.
- **Interactive Map Editing:** Load custom maps, add/edit connections, and validate routes.
- **Data Persistence:** Save and reload traveler state and map configurations via JSON serialization.
- **Robust Error Handling:** Input validation and user-friendly error dialogs.

## 🛠️ Tech Stack
- **Language:** C# (.NET 10)
- **UI Framework:** Avalonia UI
- **Architecture:** MVVM (Model-View-ViewModel)
- **Data Structures:** Custom Graph Implementation & Dijkstra's Shortest Path Algorithm
